Capstone Mini-Project

Interactive Product Inventory & Analytics Dashboard

The project demonstrates:

- Product input and validation
- Conditional logic and product categories
- Loops and inventory searching
- Functions for inventory totals and price calculations
- Array methods including "forEach()", "filter()", and "map()"
- Basic tax and discount calculations

Technologies Used

- JavaScript
- HTML (for browser-based execution, if applicable)

How to Run

1. Clone or download this repository.
2. Open the JavaScript files in a browser-based JavaScript environment.
3. For scripts using "prompt()", run them in a browser context.
4. Open the browser Developer Tools and select the Console to view the output.

Learning Outcome

These exercises helped me practice JavaScript variables, data types, operators, conditions, loops, functions, scope, arrays, objects, and basic data processing.
